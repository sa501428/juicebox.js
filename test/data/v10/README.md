These tiny binary fixtures exercise the real Straw v10 decoder through Juicebox.
`cis.hic`, `trans.hic`, and `bigint.hic` were generated with
`hic-straw-js/test/helpers/v10Fixture.js` from Straw commit
`f6b1c6c`, using these options respectively:

- `{}`
- `{trans: true}`
- `{counts: [(1n << 53n) + 1n, 1n, 5n]}`

They contain 10 BP materialized and 20 BP derived resolutions, VC vectors,
and two chromosomes with no All entry. `frag.hic` adds a 1 FRAG resolution
using `{frag: true}`. `legacy-v8.hic` is copied from Straw's
`test/data/testFiles/testBp.hic` for the unchanged legacy path.

The 4.1 GB acceptance file stays outside the repository. Run
`node scripts/validate-v10.js /path/to/file.hic` with Node 24+ to check that file
without browser access. The script validates exact derived sums, normalization,
a coarse trans query, and rendered tile buffers.


Stored All fixture provenance

`pseudo-all.hic` is generated by `hictools-c` native pre plus add-all repair.
The chromosome table is chrA=95, chrB=75, All=18. BP bins are 1,2,5,10,100;
All uses synthetic bin 1 and physical source bin 10 with group factor 1.
Source HBS cells are (chrA:14,chrA:25,2^53+17),
(chrA:14,chrB:6,13), (chrB:0,chrB:74,19). The canonical All cells are
(1,2,2^53+17), (1,10,13), (10,17,19), total 2^53+49.
The generator helper is `hictools-c/v10/tests/test_all.py:hbs`.
Run native pre with `--no-all -r 1,2,5,10,100 -f hbs`, then
`hic_v10 add-all --all-source-resolution 10 INPUT OUTPUT`.

`legacy-all.hic`, where present, is generated by `hic_pre -f short -r 100,200`
then `hic_v10 convert`, with chrA=10000000 and chrB=7500000 and source pairs
chrA:1000000/chrA:2000000, chrA:1000000/chrB:3000000,
chrB:3000000/chrB:4000000. It retains legacy All at 35 KB and has empty All
at the other global levels.

`pseudo-all-finest2.hic`, where present, uses the same HBS as pseudo-all
but pre options `--materialize 2 -r 2,4,10,100 --all-source-resolution 10`.
Its synthetic All length is 36 and finest bin is 2; the physical layout matches.
